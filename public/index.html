Einrichtung · OpenAI API

Der Betreiber richtet den OpenAI-Schlüssel auf dem Server ein: lokal mit configure-key.cmd, auf Render als geheime Umgebungsvariable OPENAI_API_KEY. Der Schlüssel gehört niemals ins Frontend oder ins Chat-Protokoll.

Ein ChatGPT-Abo enthält kein API-Guthaben. Der Website-Zugang verwendet einen separaten Benutzernamen und ein Website-Passwort.
